# Smart Mess: APK বানানোর নিয়ম (Android Studio ছাড়া)

## ধাপ
1. https://github.com এ একাউন্ট খুলুন, তারপর **New repository** দিয়ে একটা রিপোজিটরি বানান (নাম: smart-mess)।
2. এই ZIP ফাইল এক্সট্রাক্ট করে **ভেতরের সব ফাইল ও ফোল্ডার** রিপোজিটরিতে আপলোড করুন
   (**Add file → Upload files**)।
   - `.github` ফোল্ডার লুকানো থাকতে পারে। না দেখা গেলে **Add file → Create new file** চেপে নাম দিন
     `.github/workflows/build-apk.yml` এবং ZIP-এর ভেতরের একই নামের ফাইলের লেখা পেস্ট করুন।
3. আপলোড শেষ হলে **Actions** ট্যাবে যান। বিল্ড নিজে থেকেই শুরু হবে।
   না হলে **Build APK → Run workflow** চাপুন।
4. প্রায় ৫-১০ মিনিট পর বিল্ডে সবুজ টিক এলে ওই রানে ক্লিক করুন।
   নিচে **Artifacts** এর **Smart-Mess-APK** ডাউনলোড করুন, এটা ZIP, খুললে `app-debug.apk` পাবেন।
5. ফোনে APK কপি করে ইনস্টল করুন। প্রয়োজনে সেটিংস থেকে "অজানা উৎস থেকে ইনস্টল" চালু করুন।

## জেনে রাখুন
- এটা **ডিবাগ APK**, নিজে ও বন্ধুদের ফোনে চালানোর জন্য ঠিক আছে। Google Play-তে দিতে হলে
  রিলিজ সাইনিং ও AAB ফাইল লাগবে।
- অ্যাপের ডেটা এখন ফোনের মেমরিতে থাকে না (প্রোটোটাইপ), OTP ও Google লগইন নকল।
  আসল ব্যবহারের জন্য পরে Firebase যুক্ত করতে হবে।
- অ্যাপের আইকন এখন Capacitor-এর ডিফল্ট। নিজের আইকন দিতে চাইলে জানাবেন।
- অ্যাপের কোড `www/index.html` ফাইলে। ওটা বদলে আবার আপলোড করলে নতুন APK তৈরি হবে।
